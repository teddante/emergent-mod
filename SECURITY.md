# Security Policy

Emergent is a gameplay mod, but security still matters because mods are executable code.

## Supported Versions

Only the latest release on the current Minecraft/Fabric target is actively supported.

## Reporting a Vulnerability

If you find a vulnerability or supply-chain concern, please open a private security advisory on GitHub if available. If advisories are not enabled, contact the maintainer privately before publishing details.

Please include:

- Affected Emergent version or commit.
- Minecraft, Fabric Loader, and Fabric API versions.
- Reproduction steps or proof of concept.
- Any suspected malicious file, dependency, or release artifact.

Do not attach credentials, access tokens, or private server data to public issues.
